Does ZoneShift automatically adjust for Daylight Saving Time (DST)?

Yes. ZoneShift uses the official IANA Time Zone Database built into modern browsers and operating systems, automatically switching between standard and daylight offsets (such as EST/EDT, PST/PDT, GMT/BST, and CET/CEST) for any past, present, or future date you pick.

Does it support 30-minute and 45-minute UTC offsets like IST and Nepal Time?

Yes. Every standard, half-hour, and 45-minute offset is supported accurately, including India Standard Time (Asia/Kolkata, UTC+5:30), Nepal Time (Asia/Kathmandu, UTC+5:45), Australian Central Time (UTC+9:30/+10:30), and Newfoundland Time (UTC-3:30/-2:30).

Can I use ZoneShift offline on Windows, Linux, or macOS?

Yes. Click Install App in your browser to add ZoneShift as a standalone desktop application on Windows, Linux, or macOS. All assets are cached locally and zero data is sent to any server.

    Install ZoneShift on Your Desktop

    ZoneShift is a Progressive Web App (PWA). You can install it as a standalone desktop window with its own app icon, taskbar/dock launcher, and offline support on Windows, Linux, and macOS:

    Chrome / Edge / Brave (Windows, Linux, macOS)

    Click the Install icon (⊕ / monitor arrow) on the right side of the browser address bar, or open the browser menu ⋮ → Cast, save, and share → Install page as app…

    Safari (macOS Sonoma+)

    In the top menu bar, choose File → Add to Dock… to create a standalone macOS desktop app.

    Firefox / Any Browser

    Bookmark this page or pin the tab — once loaded once, it works even without an internet connection.

    🔒 Data & Privacy Policy

    ZoneShift runs 100% locally on your device. No personal data, time zone selections, or usage metrics are ever transmitted to any server.

    1. Zero Collection, Cookies, or Analytics

    This app makes no external API calls, sets no tracking cookies, and embeds no third-party analytics scripts. All time zone math uses your browser/OS built-in IANA database.

    2. Local Preferences (localStorage)

    Your saved From → To pairs, ★ favorite zones, pinned multi-zone rows, module visibility & order, 12h/24h format, and dark/light theme are saved locally in your browser under the key zoneshift_prefs_v1 so your setup persists between sessions.

    3. Offline App Cache (Service Worker)

    Static app files (HTML, CSS, JS, and icons) are cached locally in your browser's Cache Storage so ZoneShift opens instantly even without an internet connection.
